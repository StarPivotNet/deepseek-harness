## 2026-08

- **Ask the user which tier before acting**: Symptom — the experience is handled at a default tier (for example an issue is filed immediately) when the user actually wanted a local copy. Cause — the tier is the user's choice; a preset action overrides that judgment. Fix — at step 4, ask in a neutral sentence, wait for the choice, then run that tier. The question to ask, kept as the sample utterance, is `这次经验怎么处理？1. 发表 issue 2. 本地入库 3. 不入库` (How should this experience be handled? 1. file an issue 2. store it locally 3. do not store it).
