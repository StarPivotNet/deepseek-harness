# @deepseek-ai/dsh-client-ui-settings-usage

[English](README.md) | 中文

**使用统计** 设置分区。该页汇总每个可见会话的提供方 token 报告与模型墙钟时间，并绘制日历活动、每日趋势与模型占比。它不写入任何内容。

导航行位于 Skills 之后（`order: 35`）。首次挂载会用浏览器 IANA 时区调用 `usage.overview`；该 RPC 检查会话但不激活 Agent，并把 UTC 日历行重基准到调用方时区。

指标卡显示累计 token、峰值 token、最长已组装消息时长，以及活动连续天数。紧凑量级保持单行。热力图、趋势图与环形图是对该快照的本地查看状态。空热力格子使用 overlay 填充，无用量的日子仍能看出网格，52 周网格铺满卡片宽度。加载、空结果与通用失败状态只属于已挂载组件；读取失败后可以重试，且不会暴露传输细节。

## 模型体验

无。该分区渲染已记录用量的浏览器目录。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **只读快照**——该页不订阅实时用量更新。
- **无法读取的会话会被跳过**——缺失、损坏或其他无法读取的会话贡献空用量，而不是让页面失败。
- **没有个人套餐页**——只显示本地应用用量。
- **UTC 日重基准到包含该 UTC 午夜的本地日**——负时区深夜会话可能落到前一个本地日。
